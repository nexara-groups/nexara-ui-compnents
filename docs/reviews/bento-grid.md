# Bento Grid

## Round 1
`rowSpan` did not change height. The spotlight jumped on enter. Icons were part of the accessible name, and the description sat in a narrow column beside the icon.

## Round 2
Auto rows, a clamped column span, pointer-enter coordinates, and a full-width description landed. The demo then left empty cells under a wide tile.

## Round 3
The demo places the tall tile in column 1 and fills the cells beside it.

## Agreement
Approved. The mosaic is full, and the tall tile actually occupies two rows.

## Variants
spotlight, chart, quote, editorial, terminal, schedule, poster, stat, status, compare, media, brutal.
