# Round 3 — visual

**From:** [Visual designer critic](bc-503f5bb9-18a3-562e-b4de-3b569149f9da)  
**Evidence:** `docs/audit/round-3/focus-*.png` vs `docs/audit/references/{sri,rise,nexara,vdrsa}-desktop.png`.

## Verdict

**REJECT**

Round 3 named the Sri / Rise / Nexara / VDRSA anatomies, then filled most of them with gradients, initials, and serif-as-logo. Do not ship the visual pass as “reaching the live sites.”

## Keep

Type-led models that do not pretend to be photographs: `hero / studio`, `hero / devtool`, `process / written`, `process / three`, `services / four-crews`, `services / why`, `stats / year`, `countdown / event`, `leaderboard / medals`, `case-study / index`, `news / bulletin`, `cta-band / lime`, `kit / portal`.

## Redesign

`hero / ac-remote` (keep the live remote; the unit is still a drawing), `hero / clinic`, `hero / wordmark`, `hero / sports`, `case-study / tabs`, `services / checklist`, `stats / countup`, `logo-cloud / dealers`, `team / doctors`, `chapters / eight`, `kit / hvac`, `kit / healthcare`, `kit / sports`, `kit / agency`.

## Replace

Empty 21st.dev-named geometry: `hero / editorial`, `fan`, `glass-fold`, `split-cards`, `device`, `fashion`, `spiral`, `liquid`, `tilted`, `featured`. Same for case-study film/split/stack stills that are brown rectangles.

## Weak spots vs live sites

- Sri is a photographic plant and a hardware remote. Ours is mint type over an SVG split unit.
- Rise italicizes “considered.” beside an anatomical heart. Ours is a pink mark and a short ECG.
- Nexara is a metallic wordmark, orbit, assistant chip, lime CTAs. Ours is typeset NEXARA on three CSS rings.
- VDRSA is a hockey still. `hero / sports` is a dark radial.
- Dealer “logos” are Instrument Serif words, not marks.
- No original photography in the library. CSS/SVG cannot exceed those production sites.
