# Magnetic Button

## Round 1
The pull used an angle from the center, so the control lunged sideways at the midpoint and went slack at the rim. Proximity was layout padding, and the icon did not travel with the label.

## Round 2
Movement is the clamped offset from center, proximity is cancelled with a negative margin, and icons sit in the shifting label. The demo’s strength still reached the neighboring control.

## Round 3
The demo uses a wider gap, and each control’s travel stays inside its own hit pad.

## Agreement
Approved. The buttons lean toward the pointer without covering each other.
