# Round-8 self panel (wow pass, after lead reject)

Round-7 sceptical lead ([review](https://cursor.com/agents/bc-c3fab7ac-44b4-5275-a268-eeaf13349c84)) rejected all 46 families. This pass answers the named lies and the gallery pin death. It does not claim every gold chip now sits next to a top Awwwards entry.

## What changed

- Names match motion: shatter explodes letters, flap-3d flaps, matrix-rain rains, variable-morph drives Geist `wght`, physics-deck drags, particle-toss bursts on release, cylinder-3d spins on Y, magnetic-caret is a caret, countdown ticks, analog is a clock, heat-race has racing markers, podium has portraits, liquid-* mount a goo filter, hex/circuit/topo/perspective are distinct fields.
- Aliases split: `process / pin-steps` stacks sticky cards; `scrub-timeline` scrubs one step. `chapters / pin-story` pins photographic chapters; `scrub-essay` remains the scrub. `logo-cloud` magnetic vs glare are different.
- Gallery: pin/scrub cells get a `max-h` scroller; `ScrollPin` reads the nearest overflow parent, not only `window`.
- Kits: signature variants keep the industry page (`healthcare`, `agency`, `sports`, `portal`, `academy`) under a distinctive mast. They are no longer a one-card demotion.
- Ada Klein removed from the tooltip signature.

## Still not Awwwards

Orbit rings are still reused (now with pause). Tilt-glare is still the premium-card default on several families. Many signatures are finished tricks, not finished marketing pages. There is no dedicated loader family. 3D is still one lazy icosahedron.

Mandatory test: a designer would screenshot `hero / shader-void`, `hero / pin-scroll` (now with a reel), `button / liquid`, `typewriter / flap-3d`, `typewriter / matrix-rain`, `kit / shader-clinic` (full clinic under a mesh mast). They would not screenshot every orbit chip.

## A11y / perf (self)

Reduced-motion still freezes helpers. Pause exists on fields, marquees, grids, matrix rain, and orbit wrappers. 3D stays lazy. Not an AA stamp.
