Docs still caption `avatar / image` “Photographic portrait default.” Round 4’s crime was oil paint sold as photography. This is generated photoreal sold as photography. Better. Still a pack, not a shoot.
- That Kite / Solum / Nimbus / Vale / Orbit / Marble are six identities. They are one icon family. Vale is a letter V. Nimbus is three circles. They beat souvenir cubes. They are not a partner line you would send to press.
