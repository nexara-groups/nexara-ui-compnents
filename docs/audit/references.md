## 2026 trends that still ship

From current write-ups (Framer, Rajesh R Nair, PkgPulse):

- Refined glass: low saturation, contrast-safe type, solid fallbacks. Not 2021 blob-behind-frost.
- Bento only when each cell earns its size with real product content.
- Motion as material, not decoration. Reduced-motion fallbacks required.
- Variable/modern type (Geist, Instrument Serif) instead of boutique display stacks.
- Light and dark as first-class, not a dark-only demo.

## What this means for Nexara

Novelty objects (wax seals, comic panels, hazard tape, boarding passes) can be distinct and still fail the standard. Distinctness must come from **different product anatomies**, executed with the density and restraint of the sources above.
