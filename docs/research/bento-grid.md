# Bento grid — structural audit

Spotlight, status, and brutal were removed. Spotlight was a wash, status was a dot, and brutal was a shadow on the same tile. The tiles below are different documents.

| Variant | Reference | What is structurally different |
| --- | --- | --- |
| chart | [Magic UI Bento](https://magicui.design/docs/components/bento-grid) metric cells | A sparkline under the title. |
| quote | Pull quotes in [Aceternity](https://ui.aceternity.com/components/infinite-moving-cards) | A hanging quotation and an attribution. No card chrome. |
| editorial | Open editorial tiles | Type closed by a baseline rule. |
| terminal | Terminal tiles on [21st.dev](https://21st.dev/) | A path, a prompt, and monospace output. |
| schedule | Agenda rows | A time gutter beside the title. |
| scoreboard | Sports score bugs | Home and away columns, a colon, and a tide ground. Replaces poster, which repeated the editorial tile. |
| stat | [shadcn dashboard](https://ui.shadcn.com/examples/dashboard) stats | The title is the figure. |
| compare | Before/after tiles | Two labeled cells. |
| media | Media tiles in [Aceternity Bento Grid](https://ui.aceternity.com/components/bento-grid) | Children fill the well. The title sits on a scrim. |
| calendar | Month grids | A day grid on paper. |
| kanban | Board columns | A column of task chips. |
| invoice | Receipt tiles | Line items and a total on a dashed slip. |

Ideas were reimplemented. No source was copied.
