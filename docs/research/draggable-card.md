# Draggable card — structural audit

Snap-grid, carbon, and stack were removed. They were the same card with a snap, a lagging ghost, or extra sheets. The rest are different objects you can drag.

| Variant | Reference | What is structurally different |
| --- | --- | --- |
| glass | Frosted cards on [21st.dev](https://21st.dev/) | Blur, hairline, soft shadow. |
| film | Film-frame cards on [21st.dev](https://21st.dev/) | Sprocket holes on both edges. |
| sticker | Taped notes on [21st.dev](https://21st.dev/) | Tilted paper and a tape strip. |
| window | Window cards on [Aceternity](https://ui.aceternity.com/components/card-hover-effect) and OS chrome | A title bar is the only drag handle. |
| ticket | Event tickets on [21st.dev](https://21st.dev/) | A perforated stub. |
| polaroid | Instant-photo cards on [21st.dev](https://21st.dev/) | A thick caption band. |
| dossier | File cards | Ruled lines and a corner stamp. |
| receipt | Thermal receipts | Monospace slip and a torn foot. |
| comic | Comic panels on [Uiverse](https://uiverse.io/) | Ink border, halftone, hard offset shadow. |
| playing | Playing-card UI on [Uiverse](https://uiverse.io/) | Corner rank and suit. |
| boarding | [Flight card](https://21st.dev/@ravikatiyar162/components/flight-card) | Paper itinerary: origin, destination, flight, gate, and seat. Not an event stub. |
| postcard | Postcard UI | A stamp box and an address side, not a photo caption. |

Ideas were reimplemented. No source was copied.
