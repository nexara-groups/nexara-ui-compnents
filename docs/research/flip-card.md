# Flip card — structural audit

The previous set (yaw, pitch, hinge-left, shuffle, fade, slide, split, iris, peel, box, shutter, fold) was one card and a different turn. Those were removed. Every object now turns on Y. The faces are different products.

| Variant | Reference | What is structurally different |
| --- | --- | --- |
| credit | Bank-card UI on [Uiverse](https://uiverse.io/) | Chip, number, and a signature strip. |
| badge | Visitor badges | Name and a barcode reverse. |
| playing | Playing cards on [Uiverse](https://uiverse.io/) | Rank, suit, patterned back. |
| product | Product flips on [21st.dev](https://21st.dev/) | Stage in front, specs behind. |
| flashcard | Index cards | Term and definition. |
| ticket | Event tickets | Admit face and a stub. |
| profile | Profile cards on [21st.dev](https://21st.dev/) | Portrait and a biography. |
| pricing | Pricing cards in [shadcn blocks](https://ui.shadcn.com/blocks) | Price in front, included list behind. |
| passport | Passport covers | Emblem cover and a data page. |
| vinyl | Record sleeves | A disc and a track list. |
| book | Book covers | Cloth cover and a blurb. |
| postcard | Postcards | A picture and a written side with a stamp. |

Ideas were reimplemented. No source was copied.
