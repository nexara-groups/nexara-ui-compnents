# Marquee — structural audit

Fade, ping-pong, cylinder, vertical, spotlight, stepped, parallax, overlap, velocity, dwell, reverse-hover, and cascade were removed. They were one row of chips and a different motion. The track still loops. The things on the track change.

| Variant | Reference | What is structurally different |
| --- | --- | --- |
| logos | [Magic UI Marquee](https://magicui.design/docs/components/marquee) logo clouds | Wordmarks. |
| quotes | [Aceternity Infinite Moving Cards](https://ui.aceternity.com/components/infinite-moving-cards) | Quote cards. |
| ticker | News tickers | A live stamp and a tape. |
| stubs | Ticket stubs | A dashed tear and an admit cell. Replaces reviews, which repeated the quote cards. |
| filmstrip | Film strips | Sprocketed frames. |
| pills | Tag rows | Capsules. |
| stats | Metric strips | A figure over a label. |
| hazard | Caution tape | Diagonal stripes and a warning. Replaces announcement, which repeated the ticker bar. |
| profiles | Avatar marquees | Round marks and initials. |
| log | Terminal logs | A prompt and log lines. |
| tiles | App-icon rows | Squircles with a glyph. Replaces wordmark, which repeated the logo text. |
| medals | Medal rows | A ribbon tab over a rimmed disc. Replaces awards, which were another chip. |

Ideas were reimplemented. No source was copied.
