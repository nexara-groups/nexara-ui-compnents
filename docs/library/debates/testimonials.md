# Testimonials — role debate

Six agents argued before implementation. They did not agree on names. They agreed on the kills.

## Roles

- Trend researcher
- Product / UX strategist
- Visual designer
- Motion designer
- Front-end (API / perf / a11y)
- Sceptical creative director

## Fights

**Marquee vs evidence.** Researcher: marquees are the 2025 volume signal. UX: nobody reads a moving quote. CD: a marquee is a different family. Converged: no marquee id. Strongest quote is static.

**Stars.** Visual refused gold stars as chrome. UX: a rating can be a slot, not an id. Converged: no star variant.

**3D wall.** Motion wanted Helio’s shallow masonry. FE: pointer lean, reduced = `pin`. CD: if the default is a candy sphere of quotes, kill it. Converged: `wall` is a room of cards, one key light.

**Voice notes.** Researcher noted 2026 audio proof. FE: no autoplay, transcript required for the advanced id. Converged: `voice` is waveform + transcript.

**Defaults.** CD killed Jack, Helio studios, five-star rows. Empty `items` is empty.

**What died.** Marquee. Stars-as-variant. Tweet skins. Glass swiper. A 12th logo cloud.
