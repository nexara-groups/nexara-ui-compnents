# Bento — role debate

Six agents argued before implementation. They did not agree on names. They agreed on the kills.

## Roles

- Trend researcher
- Product / UX strategist
- Visual designer
- Motion designer
- Front-end (API / perf / a11y)
- Sceptical creative director

## Fights

**Section vs chrome.** UX wanted a feature section people paste on Monday. Visual refused item skins on the old `bento-grid.tsx`. CD: if every thumbnail is a rounded card with an icon, the family does not exist. Converged: this is a *section* family. Eleven mechanisms. The old grid file stays a primitive.

**Fake hierarchy.** Researcher: 2026 bento is unequal cells. UX: forcing a hero cell when four features are equal is a lie. Visual: `reel` exists for honesty. Converged: `mosaic` ranks; `reel` does not.

**Working tiles.** Motion wanted live sparkline/filter/compare in every advanced cell. FE: pause offscreen, slots not required widgets, no Helio ping. CD: widgets without a still are demos. Converged: `dock` hosts instruments as slots; empty is empty.

**Desk vs grid.** Visual demanded named objects that do not share a radius. UX said that is a landing page. Converged: `desk` is advanced; BASIC never ships object theater.

**Scroll hijack.** Motion proposed scroll-morph tiles. FE and UX killed page-length pins. Converged: `inspect` is control-first; `reflow` is pointer/focus, static under reduced motion.

**What died.** Icon-card farms. Glow borders. Helio lamp/pipes as defaults. Item-variant costumes. A 12th “gallery” (that is another family).

## Converged ship list (11)

| id | tier | Mechanism | Motion idea |
| --- | --- | --- | --- |
| `mosaic` | basic | Ranked spans. One cell is twice the others. | Nothing required. |
| `reel` | basic | Equal proof cells in a strip. | None. |
| `sheet` | basic | Paper compartments. Type and rules. | None. |
| `well` | basic | Evidence crops. Caption is a caption. | Plate seats once. |
| `dock` | intermediate | Cells host working instruments. Slots. | Tick. Pause offscreen. |
| `stage` | intermediate | An index of cells drives one shared plate. | Snap on select. |
| `spec` | intermediate | The figure occupies the cell. | Optional count. |
| `expand` | intermediate | The selected cell becomes the detail. | Layout spring. |
| `inspect` | advanced | A control scrubs their media inside one cell. | Control-first. |
| `desk` | advanced | Named objects on a plate. They do not share a radius. | Pointer optional. |
| `reflow` | advanced | Focus reweights the mosaic. Neighbours yield. | Layout spring. |

## Sign-off bar

Each id is a different mechanism. Tokens restyle it. Empty tiles omit chrome. Reduced motion is the end state. Helio is a docs tenant.
