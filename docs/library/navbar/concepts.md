# Eighteen navbar concepts (each a different visual language)

Mockups: `docs/library/navbar/mockups/0N-*.html` and `.png`. Chrome is original. Stills reused from the hero library as plates the nav sits on — not ports of 21st/Aceternity/Magic UI.

| # | id | language | default product | tier | mobile |
| --- | --- | --- | --- | --- | --- |
| 01 | `pill` | Frosted floating capsule, magnetic links | Lumen design OS | basic | Sheet of destinations with staggered type |
| 02 | `banner` | Announcement strip that the bar absorbs | Lumen waitlist | basic | Banner stacks above a full-width sheet |
| 03 | `tabs` | Liquid physics indicator | Iris canvas | basic | Horizontal chip scroller, not a burger |
| 04 | `clinic` | Named-doctor medical bar | Harbor Clinic | basic | Visit card + doctor status |
| 05 | `league` | Night-meet scoreboard strip | Harbor Athletic | basic | Fixtures list + Get tickets |
| 06 | `pop` | Colour chips, Saturday energy | Playfield Academy | basic | Class cards in a courtyard sheet |
| 07 | `mega` | Live-preview campaign panel | Folio agency | intermediate | Campaign stack, one preview at a time |
| 08 | `command` | The field is the navigation | Relay coding desk | intermediate | Full-screen palette |
| 09 | `follow` | Cursor spotlight across the index | Northbound studio | intermediate | Spotlight list |
| 10 | `crumb` | Docs path + reading progress | Prism docs | intermediate | Path collapses to Here + % |
| 11 | `kiln` | Plant selector + live temperature | Kiln Mechanical | intermediate | Plant card + Call the shop |
| 12 | `split` | Bar that splits on scroll | Vesper device | intermediate | Wordmark / CTA stack, links as list |
| 13 | `island` | Notch console that morphs job | Nimbus ops | advanced | Island expands to a tray |
| 14 | `curtain` | Viewport of type | Kin fashion film | advanced | The curtain *is* the mobile menu |
