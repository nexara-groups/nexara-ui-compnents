# Navbar trend breakdown (inspiration only)

Sources: Pinterest, 21st.dev, Aceternity, Magic UI, Dribbble, Awwwards, Godly, Land-book, Mobbin, Linear, Vercel, Raycast, Arc, Framer, Stripe, Apple. Stills in `refs/`. None of this is ported.

## What the market actually shows

1. **Hairline marketing bars.** Linear, Vercel, Cursor, Next.js: full-bleed dark strip, 4–5 words, one CTA. The bar tries not to be an object. Mega is a product taxonomy, rarely a picture.
2. **Floating glass pills.** 21st.dev / Aceternity / Wensity: `rounded-full` + `backdrop-blur` centered over the hero. The default AI-era cliché. Magnetic hover is the only motion most of them have.
3. **Mega with pictures.** Framer, Stripe, stronger 21st megas: the panel is a layout, not a link list. Previews win.
4. **Command as nav.** Raycast’s product is the field. Marketing sites fake it with a window. Almost nobody *is* a command field in the header.
5. **Apple dissolve.** The bar blurs and shrinks into the hero. Global mega. Hard to copy without looking like Apple.
6. **Dock / island.** Magic UI dock is Finder. Dynamic-island ports are iPhone screenshots. The *jobs* (magnify by proximity, morph the same surface) are worth stealing, not the chrome.
7. **Industry.** Clinic, HVAC, sports, school, agency OS — almost absent from component galleries. Those galleries are SaaS-only.

## What we will not do

- Port Aceternity floating-navbar, navbar-menu, or resizable-navbar.
- Port Magic UI dock icons.
- Recolor one pill eighteen times.
- Ship a hamburger that dumps the desktop list.

## What we take as pressure, then invent

Objecthood. Live chrome (named people, temperatures, times, previews). A designed small screen. Keyboard. Reduced-motion last-frame. Sixteen different objects sitting on a first screen.
